# docs/scholarship/ — Index

Seventeen per-scholar research reports plus a cross-cutting synthesis,
written to ground the Radical Axis (`WORLD_DESIGN.md` §4) and the planned
"clerical underworld" side-content expansion in the actual current state
of scholarship on medieval ritual magic, monastic magic ownership, and
the historiography responding to Kieckhefer. Each report is a secondary
research aid, not itself a `sources[]`-grade citation for game data —
see each file's own "Citation note."

| File | Scholar | One line |
|---|---|---|
| `kieckhefer.md` | Richard Kieckhefer | Coined the "clerical underworld"; the field's founding taxonomy of magic's registers. |
| `fanger.md` | Claire Fanger | This game's canonical source; *Rewriting Magic* and the reflexive method behind the pencil hand. |
| `watson.md` | Nicholas Watson | Announced John's modern rediscovery (McMaster MS); co-editor of the critical edition. |
| `veronese.md` | Julien Véronèse | Modern critical edition of the *ars notoria* itself — what John practiced before he rewrote it. |
| `page.md` | Sophie Page | Monks as insiders, not underworld figures: monastic ownership of magic texts (Canterbury). |
| `klaassen.md` | Frank Klaassen | The "whitening" thesis — illicit ritual magic laundered into licit devotion, generation by generation. |
| `lang.md` | Benedek Láng | Manuscript census as historical argument; Central European learned-magic libraries. |
| `newman.md` | Barbara Newman | Discernment of spirits as a contested social/rhetorical process, not a private checklist. |
| `carruthers.md` | Mary Carruthers | Memory as trained craft; the *ars notoria* as a shortcut to labor monks already knew intimately. |
| `camille.md` | Michael Camille | The Gothic margin as licensed, text-keyed commentary — warrant for the drollery-pressure mechanic. |
| `bailey.md` | Michael D. Bailey | Magic/religion/science as contested categories, actively redrawn by whoever classifies. |
| `veenstra.md` | Jan R. Veenstra | Courtly magic accusation as interested political argument, not neutral report. |
| `mesler.md` | Katelyn Mesler | Cross-cultural (Jewish-Christian) transmission and reputation — the project's thinnest-covered angle. |
| `mathiesen.md` | Robert Mathiesen | Solomonic manuscript typology (*Clavicula Salomonis*); real-world analogue of the stemma system. |
| `peters.md` | Edward Peters | Legal-institutional history of how magic became a prosecutable category. |
| `flint.md` | Valerie I.J. Flint | Deep-time thesis: the early Church accommodated, not just suppressed, magical practice. |
| `conti.md` | Fabrizio Conti | Observant Franciscan preaching on superstition — Renaissance-era, thinnest direct relevance. |
| `NARRATIVE_DESIGN_SYNTHESIS.md` | — | Cross-cutting synthesis, designer-scholar voice: where the seventeen agree, disagree, and where the game already does uncredited scholarly work. Read this after the individual reports, not instead of them. |

**Reading order for a new session:** the synthesis first if you want the
punchline, the individual reports first if you want the sourcing under
it. Both assume familiarity with `HANDOVER.md`, `DESIGN.md`,
`STYLE_GUIDE.md`, and `WORLD_DESIGN.md` §4 — these reports connect to
those systems by name throughout and don't re-explain them.
